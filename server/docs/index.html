DevCamper Backend

A Node.js/Express REST API with MongoDB for managing bootcamps, courses, reviews, and users. Includes local auth (JWT) and optional OAuth (Google, GitHub).

Stack

  • Node.js, Express
  • MongoDB (Mongoose)
  • JWT auth (cookies/headers)
  • Passport (Google/GitHub OAuth)
  • Security middleware: helmet, xss-clean, hpp, express-mongo-sanitize, rate limiting
  • File uploads, email (SMTP), and geocoding

Prerequisites

  • Node.js 18+
  • MongoDB running locally (or a connection string)

Quick Start

cd server
npm install
npm run dev

Server listens on port 8080 by default.

Swagger UI: http://localhost:8080/api/docs (served from swagger.yaml)

Environment Variables

Create .env in server/ (sample values shown below):

NODE_ENV=dev
MONGO_URI=mongodb://localhost/devcamper
DEVCAMPER_JWT=change_me

# SMTP (for forgot password)
SMTP_HOST=smtp.mailtrap.io
SMTP_PORT=2525
SMTP_EMAIL=your_user
SMTP_PASSWORD=your_pass
FROM_EMAIL=admin@devcamper.com
FROM_NAME=DevCamper

# Geocoder
GEO_CODER_PROVIDER=mapquest
GEO_CODER_API_KEY=your_mapquest_api_key

# Uploads
MAX_UPLOAD_SIZE=1000000
FILE_UPLOAD_PATH=./public/uploads

# OAuth (optional)
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
GOOGLE_CALLBACK_URL=http://localhost:8080/api/v1/auth/google/callback

GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret
GITHUB_CALLBACK_URL=http://localhost:8080/api/v1/auth/github/callback

# Session for Passport
SESSION_SECRET=change_session_secret

Authentication

  • Local (email/password)

    • POST /api/v1/auth/register
    • POST /api/v1/auth/login
    • POST /api/v1/auth/me (requires Authorization: Bearer <token>)
    • GET /api/v1/auth/logout
    • POST /api/v1/auth/forgotpassword
    • PUT /api/v1/auth/resetpassword/:resettoken
    • PUT /api/v1/auth/updatedetails (auth)
    • PUT /api/v1/auth/updatepassword (auth)

  • OAuth (optional)

    • GET /api/v1/auth/google
    • GET /api/v1/auth/google/callback
    • GET /api/v1/auth/github
    • GET /api/v1/auth/github/callback

After a successful OAuth callback, the server responds with a JWT (and may set a cookie). Use it with /auth/me.

API Endpoints (Summary)

Base URL: http://localhost:8080/api/v1

  • Auth: /auth/* (see above)

  • Bootcamps: /bootcamps

    • GET /bootcamps (admin/publisher)
    • POST /bootcamps (auth)
    • GET /bootcamps/:bootcampid
    • PUT /bootcamps/:bootcampid (publisher/admin)
    • DELETE /bootcamps/:bootcampid (publisher/admin)
    • PUT /bootcamps/:bootcampid/photo (publisher/admin)
    • GET /bootcamps/radius/:zipcode/:distance (auth)

  • Courses: /courses

    • GET /courses (all courses)
    • GET /bootcamps/:bootcampid/courses (courses of a bootcamp)
    • POST /bootcamps/:bootcampid/courses (auth)
    • GET /courses/:courseid
    • PUT /courses/:courseid (admin/publisher)
    • DELETE /courses/:courseid (admin/publisher)

  • Reviews: /reviews

    • GET /reviews (all reviews)
    • GET /bootcamps/:bootcampid/reviews (reviews for a bootcamp)
    • POST /bootcamps/:bootcampid/reviews (user/admin)
    • GET /reviews/:reviewId
    • PUT /reviews/:reviewId (if implemented)
    • DELETE /reviews/:reviewId (if implemented)

  • Users (Admin only): /users

    • GET /users
    • POST /users
    • GET /users/:userId
    • PUT /users/:userId
    • DELETE /users/:userId

Example Requests

Register:

curl -X POST http://localhost:8080/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"John","email":"john@example.com","password":"password123"}'

Login:

curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"john@example.com","password":"password123"}'

Me (replace TOKEN):

curl -X POST http://localhost:8080/api/v1/auth/me \
  -H "Authorization: Bearer TOKEN"

OAuth (browser):

  • GitHub: http://localhost:8080/api/v1/auth/github
  • Google: http://localhost:8080/api/v1/auth/google
